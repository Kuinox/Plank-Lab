Portable INT32 width screens: ordered public-API results for widths 1, 8, 12, 24, 31, and 32. The two generalized candidates were rejected after sustained regressions.

Width-12 experiment: ARM INT32 decoder timing improved this specific case, but the PR is being generalized across widths. The page retains the ordered samples and source revisions.

Focused Ryzen 7900X source experiments from September 29, 2026, against Plank 60c4749 and Plank-Lab 067763e. All numbers are milliseconds for the Plank public library API, isolated to one CPU. Each run has 100 ordered iterations. Candidate values appear first, followed by two baseline runs. First ten is their sum, middle sixty is the sum of iterations 21–80, and late twenty is the median of iterations 81–100.

These are diagnostic screens, not accepted fixes. Every candidate had a middle or late regression, or failed to clear its first-use loss. None was opened as a performance PR. Download ordered samples and run metadata (JSON).

ARM Neoverse N1 constant-delta decoder experiment (September 29): the synthetic workload uses 12-bit residuals and did not exercise this candidate's zero-bit-width path, so the result is inconclusive.
