ARM INT32 12-bit decoder experiment

September 29, 2026 · Neoverse N1 · Plank base 60c4749 · patch 06e0f6a · Plank-Lab 067763e. This experimental patch decodes four 12-bit residuals from each six-byte packed group on the portable INT32 delta path. This is the path used by the synthetic benchmark's values, which advance by 37 modulo 2048.

The published Plank column read used 1,000,000 rows, one pinned CPU, 100 ordered ColdStart iterations per run, and no warmups. Runs were serial A/B/B/A.

Scope limitation: this code handled only width 12. PR #152 is now a draft while the decoder is generalized across widths. These measurements remain a record of this exact experiment.

Both patch runs improved first use, middle throughput, and late throughput against both bracketing baselines. On the closer baseline, first ten improved 37%, middle sixty 5–6%, and late median 5–6%. The patch passed 1,095 tests with AVX2 disabled and 1,095 tests with default x64 settings. Review performance fix PR #152.
